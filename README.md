Project: FNOL Claim Routing Script

Description
This Python script processes a First Notice of Loss (FNOL) text input,
extracts key claim details, checks for missing or suspicious information,
and recommends the appropriate processing route.

How to Run
1. Ensure Python 3 is installed
2. Place `main.py` and `sample_fnol.txt` in the same folder
3. Run: `python main.py`

Output
The script outputs a JSON object containing extracted fields,
missing fields, and the recommended claim routing decision.
